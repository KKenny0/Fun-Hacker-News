## 核心主题

这篇文章由软件架构领域权威 Martin Fowler 发表，讨论如何构建**可靠**的 AI Agent 系统。文章聚焦于大型语言模型（LLM）在实际生产环境中面临的可靠性挑战，以及工程团队如何应对这些挑战。

## 技术背景

AI Agent（智能体）是当前 AI 领域的热门方向，它能够自主决策、调用工具、完成复杂任务。但与传统的确定性软件系统不同，LLM 本质上是概率性的，这带来了新的可靠性问题：

- **输出不确定性**: 相同的输入可能产生不同的输出
- **推理复杂性**: 多步骤的推理链容易出错
- **工具调用风险**: 调用外部 API 或数据库可能失败
- **状态管理困难**: 维护长期上下文和记忆变得复杂

### 1. 可靠性的定义与维度

在 AI Agent 语境下，"可靠性"可能包含：
- **功能可靠性**: Agent 能否持续完成预定任务
- **可观测性**: 能否追踪 Agent 的决策过程

- **安全性**: Agent 行为是否符合预期边界

- 幻觉导致的错误决策

- 长时间任务中的上下文丢失
