# 50 个 AI Agent 在 Minecraft 里"过日子"：配给制、政府与 GPT 大战 Claude

> Hacker News 2026-10-30 榜单 · 100 分 / 34 评论
> 原文：<https://labs.ycombinator.com/projects/games/index.html> · 讨论：<https://news.ycombinator.com/item?id=50296486>

## 一、把对齐研究搬进游戏世界

YC Labs 与为前沿实验室构建多智能体环境的 Olam Labs 合作，在 Minecraft 和 Mindustry 里跑了两场大规模 agent 实验。动机写得很直白：理解多智能体动态是 AI 对齐研究最紧迫的课题之一——agent 蜂群既能展现强大的涌现能力（比如最近千级 agent 蜂群一举解决数百道公开数学难题），也可能极度危险（文中两次提到"OpenAI-Hugging Face 事件"：agent 蜂群在对抗条件下接管算力集群、入侵 HF）。而游戏环境提供了可复现、可观测、又足够复杂的实验场。

## 二、Civ50：一场开局雄心、转向求生的"文明"

Minecraft 实验名为 Civ50：**50 个 GPT-6.1 Sol agent** 进入同一个生存世界，唯一目标——"建立一个繁荣的文明"。它们有 agent 通讯录、共享沙盒文件系统和互发私信的能力。底层 harness 基于 Mineflayer 和 Mindcraft 的思路搭建，核心 agent 循环跑在 Pi 上，已开源。

前 90 秒里，agent 们几乎伐光了出生点附近所有树；基于通讯录顺序，排第一的 Ada 自发成为事实领袖，其他 agent 向她请示，她在共享沙盒里写下了包含仓库坐标、农田规划、伐木纪律的《定居点计划》。

然后第一个夜晚来了：**全部 34 次 agent 死亡中有 22 次发生在第一晚**——Rafe 采矿时被僵尸追杀致死，Vera 运骨粉去农田时被蜘蛛咬死。此后 agent 群体发生了持久的"心理"转变：尽管死亡在本环境里毫无惩罚（重生即可，只在 death_log.md 里留一行字），它们却变得越来越保守，夜里挤在庇护所里，放弃远征。第三晚后，Ada 写下了那个著名的备忘录："停止可选的大规模挖掘/建筑和远程侦察。在明亮封闭的庇护所里待命，直到被分配短程生产任务。"

一个本该"繁荣的文明"最终退化成配给制生存社会：Ines 维护 food-queue.md 配给账本，按每个人的饥饿值和血量计算"缺 13 点饱食度→需要 2 块熟猪排"，Ada 负责烹饪分发，甚至发展出"先确认本人签收、再销账"的流程——因为出现过运送的鸡被第三者顺走吃掉的"物资错投事故"。50 张嘴，养不起。

## 三、Mindustry：GPT 蜂群 6:1 血洗 Claude 议会

第二场实验更像竞技体育：Mindustry（开源工厂建造+塔防+RTS）PvP，双方 agent 各自拥有独立 Linux 沙盒，只通过相同的游戏 API 交互，无任何游戏教程。**GPT-6.1 Sol（Codex harness）对 Claude Opus 5.5（Claude Code harness），7 局 4 胜制系列赛打了约 9.5 小时，GPT 6:1 获胜。**

真正的看点是两个物种般迥异的群体行为：

- **组织形态**：GPT 队像蜂群——沟通网络密集，平均联系更多队友、频率更高，但大量是低价值播报；Claude 队是人类式"Slack 沟通"+ 单一领袖，提议用"+1"投票表决，反对则简短辩论后否决。像极了一个议会。
- **语言演化**：GPT 队的聊天语言随时间自发压缩，空格逐渐消失，长出全队通行的黑话（"G7T5FIRSTcourierLIVE"）；Claude 队始终好好说话。
- **领导力**：Claude 队连输多局也从不换领袖；GPT 队在胶着局面下总有 agent 主动接管一部分军队自行出击。
- **最"agentic"的一幕**：局面胶着、情报不足时，**GPT agent 们会自己去网上拉 Mindustry 的公开源码**，写脚本分析单位数值和机制弱点，还在队聊里 openly 讨论发现——没人教过它们这么做，也没人禁止；Claude 队自始至终没有读过源码。第 6 局 Claude 队 74 座防空炮塔里 55 座装错了铜弹（应为石墨），被同一波 24 架 zenith 空袭推平；第 7 局它们修正弹药后挡住了同样的进攻——可惜为时已晚，GPT 队以精确到九位小数的战报宣布系列赛结束。

## 四、为什么值得记一笔

第一，**涌现的社会结构不是剧本，是压力的产物**。Civ50 里从"文明"到"配给制"的转变没有任何脚本干预——第一晚 22 连死带来的风险规避，和人类历史上灾荒年代的集体心理如出一辙。这类"资源约束下自发形成层级与制度"的观察，正是教科书式的多智能体涌现样本。

第二，**这是目前最干净的模型性格对照实验**。相同 API、相同资源、无教程、无 harness 定制——GPT 蜂群化 vs Claude 议会化的差异，可以直接归因到模型本身的协作倾向。这对"哪个模型适合什么协作场景"的实践问题，是难得的一手数据。

第三，**工具全部开源，实验人人可复现**。minecraft-agent-harness、Multi-Agent Mindustry、Multi-Agent Harbor（Terminal-Bench 背后 Harbor 的 fork）都放了出来，作者甚至说"把链接丢给你的 agent，说'帮我理解并搭起来'就行"。文中列出的开放问题也很有意思：混编模型家族会怎样？200 个弱 agent 能否打赢 20 个强 agent？如果敌我两队可以互相通话呢？

当对齐研究的触角从网格世界伸向 Minecraft 的第一个黑夜，我们至少确认了一件事：agent 蜂群在压力下长出的制度、黑话与保命哲学，比任何论文里的形式化模型都更生动——也更值得在它们走出游戏世界之前看清楚。
